Proyek Aplikasi: mencraft.id

Aplikasi Python Pemesanan Bucket

mencraft.id

"The Perfect Gift at any Time"

mencraft.id adalah aplikasi sederhana untuk mempermudah alur pemesanan bucket secara sistematis. Dibuat menggunakan Python dengan penyimpanan data pada file JSON sebagai proyek belajar logika pemrograman.

Python 3 File JSON Manajemen Pesanan

Fitur Utama mencraft.id

1
Pilih Bucket

Memilih jenis bucket yang tersedia beserta informasi harga produk.

2
Tambah Pesanan

Memasukkan jenis bucket dan menentukan jumlah pesanan yang diinginkan.

3
Kelola Pesanan

Memperbarui jumlah pesanan maupun membatalkan item dari daftar belanja.

4
Checkout

Menghitung total pembayaran dan menyimpan riwayat transaksi ke database JSON.
