3 Pilar Fokus Minat Keilmuan

Penerapan tata letak 3 kolom sejajar sesuai kaidah Modul 5 Layouting CSS untuk 3 fokus minat utama:

1. Web Design

Menguasai pembuatan desain antarmuka, tata letak visual estetis (CSS3), responsivitas multi-perangkat, dan pengalaman pengguna (UI/UX) yang intuitif.

2. Jaringan Komputer

Mempelajari arsitektur jaringan komputer, protokol komunikasi data, konfigurasi routing & switching, serta pengelolaan hosting dan server web.

3. Internet of Things (IoT)

Mengeksplorasi integrasi perangkat keras mikrokontroler, pemrograman sensor cerdas, serta komunikasi data IoT untuk sistem otomasi modern.

1. Mengatur Border

2. Mengatur Lebar (Width)

Lebar 120px, tinggi otomatis

width: 120px; border: 3px...

3. Mengatur Tinggi (Height)

Dimensi 180px x 120px

width: 180px; height: 120px;

4. Transparansi & Hover

Opacity 0.4 & Hover 1.0 (Arahkan Mouse)
