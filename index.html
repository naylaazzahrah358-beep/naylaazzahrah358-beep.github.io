Proyek Aplikasi: mencraft.id

Aplikasi Python Proyek Belajar

mencraft.id

"The Perfect Gift at any Time"

mencraft.id adalah program aplikasi sederhana berbasis console untuk mempermudah alur pemesanan bucket. Dibuat menggunakan bahasa Python dengan penyimpanan data riwayat menggunakan file JSON.

Python 3 Format File JSON Kelola Pesanan Sistem Checkout

Fitur Utama Aplikasi mencraft.id

1
Pilih Bucket

Menampilkan katalog jenis bucket yang tersedia beserta harga dalam menu terstruktur.

2
Tambah Pesanan

Memilih produk dan menentukan jumlah yang ingin dibeli ke dalam daftar pesanan aktif.

3
Kelola Pesanan

Dapat mengubah jumlah pesanan maupun menghapus item pilihan dari daftar keranjang.

4
Checkout Pesanan

Menghitung total pembayaran dan menyimpan riwayat transaksi ke dalam file database JSON.
